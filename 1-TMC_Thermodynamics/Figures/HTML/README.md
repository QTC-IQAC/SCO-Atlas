# Interactive Ligand Maps

Notebook `1-TMC_Thermodynamics/Notebooks/4-Ligand_Composition.ipynb` generates one
interactive map and one associated data table for each ligand denticity:

- `Grid_Map_d1.html` and `Grid_Map_d1.csv`
- `Grid_Map_d2.html` and `Grid_Map_d2.csv`
- `Grid_Map_d3.html` and `Grid_Map_d3.csv`
- `Grid_Map_d6.html` and `Grid_Map_d6.csv`

The **Color by** selector in each HTML file switches among the available
thermodynamic and bibliographic properties without changing the ligand-family
layout. Static manuscript figures are generated locally in the parent
`1-TMC_Thermodynamics/Figures/` directory and are not tracked because
the analysis notebooks reproduce them.
