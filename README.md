# SCO ATLAS Results

This repository reports results from studies of the SCO ATLAS, a chemically
aware dataset of Fe(II)N6 complexes represented and navigated with SCOPE.
Accompanying notebooks, derived tables and interactive figures allow readers
to inspect the analyses and reproduce the reported findings.

## Reported studies

| Directory | Study |
| --- | --- |
| [1-TMC_Thermodynamics](1-TMC_Thermodynamics/README.md) | *Mapping How Ligands Shape Spin-State Thermodynamics in Fe(II)N₆ Complexes: Insights from the SCO ATLAS* |

The first study analyses gas-phase electronic and vibrational thermodynamics,
ligand composition, coordination geometry and their relationships to spin
crossover. Computed molecular crossing temperatures are distinct from
experimental crystal transition temperatures.

## Underlying ATLAS data

The SCOPE System objects and quantum-chemistry computation files are archived
separately on [Zenodo](https://doi.org/10.5281/zenodo.23083798). This repository
contains the accompanying analyses and derived results.

The archive's data hierarchy is:

```text
Data/
├── 1-Sources/          Experimental structures and SCOPE Source objects
├── 2-Systems/          Serialized SCOPE System objects
└── 3-Computations/
    └── <system>/
        └── isolated/  Gas-phase molecular calculations
```

Serialized Systems connect experimental sources, structures, workflows,
calculations and registered results. Follow the archive's README to extract,
verify and configure the data.

## Reproducing the first study

The first study requires Python 3.12, SCOPE 0.9.6 with both `scope` and
`scope_sco`, and the complete ATLAS data archive. Its
[study README](1-TMC_Thermodynamics/README.md) describes configuration and the
numbered notebook sequence. Set the data and output paths in each notebook's
configuration cell before running it.

SCOPE System and Environment files contain serialized Python objects and
should only be loaded from a trusted copy of the dataset.
