# SCO ATLAS Results

This repository reports scientific results obtained from the SCO ATLAS. Its
notebooks, derived tables and interactive figures accompany individual studies
and support inspection and reproduction of their findings.

Read the repository README and the relevant study's README before editing.
Keep documentation focused on the reported results, scientific methods, data
provenance and reproduction requirements.

- Preserve numerical conventions, units, identifiers and links between results
  and their underlying analyses.
- Follow the software requirements documented for each study. The first
  gas-phase study targets SCOPE 0.9.6, including `scope` and `scope_sco`.
- Keep gas-phase molecular crossing temperatures, periodic calculations and
  experimental transition temperatures scientifically distinct.
- Keep published tables, figures and scientific descriptions mutually
  consistent when making a requested correction.
- Do not regenerate computationally expensive analyses without task scope.

The first study is in `1-TMC_Thermodynamics/`. Its numbered notebooks 0–6 form
the main analysis sequence; `D-` notebooks document focused diagnostics.
